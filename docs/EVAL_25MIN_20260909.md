## B.3 Leitura

1. **Cadência 5× sem perder rigor:** 366 ciclos com guarda pareada completa (não é "modo rápido" —
   é o screening podando candidatos fúteis no estágio barato). O fix pós-"8h" validado em escala real.
2. **Sistema imune íntegro em volume:** 366/366 rejeições com 0 aplicações. O baseline continua
   num ótimo local; o harness continua não carimbando.
3. **Transientes recorrem, regime não muda:** pico tardio (8.46 @2.983) e 145 rounds com cap≥6
   (último @3.394) mostram que a linhagem semântica re-explora — mas regressão 0.505 (cara-ou-coroa)
   e curvatura negativa mantêm `local_stagnation`. **5ª confirmação do ADR-0002.**
4. **Macros não saturaram desta vez** (4 vs cap 24): dinâmica de promoção varia por linhagem —
   o sinal `macro_cap_saturated` (F1) existe exatamente para não generalizarmos uma run.
5. **F1+F3 validados em escala:** 3.660 rounds auditados 1→3660, JSONL 100% íntegro, 0 exceções,
   `verify_run_continuity.py` verde. Runs de 100+ min são só repetição deste protocolo.
