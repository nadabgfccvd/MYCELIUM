# EC3 — Projeto real de terceiros: `ilen()` no more-itertools (Fase 2)

- **Data:** 2026-09-09 · **Alvo:** `more-itertools` @ `19ddb972` (pinado),
  pacote real de terceiros, ~7.200 linhas, testes próprios
- **Hipótese:** `ilen()` usa a variante rápida para iteradores, mas não tem
  fast-path `len()` para sized (list/tuple — o caso comum)
- **Protocolo:** harness genérico, variante `patch` (6 linhas), 7 seeds primas ×
  5 repeats, workload honesto 70% sized / 30% iteradores, IC 95% BCa
- **Gate:** `pytest tests/test_more.py -k ilen` verde sob a variante antes de medir
- **Dados brutos:** `.mycelium_benchmarks/ec3_report.json` (+ sweep no alvo)
- **Reprodução:** `bash scripts/reproduce_ec3.sh` (requer rede p/ o clone)
- **PR:** pack pronto em `docs/EC3_PR_PACK.md` (abertura manual — 5 min)

## Resultado (baseline 9.209 ms → variante 4.098 ms no mix)

| Métrica | Valor |
|---|---|
| Ganho médio no mix 70/30 | **+55,5%** |
| Δ pareado (7/7 seeds positivas) | +5,11 ms, IC 95% [+4,14; +6,06] |
| p (única comparação) | **0,0078**, dz = 3,71 |
| Caso puro lista (microbench) | ~3.600× (271,6 µs → 0,1 µs) |
| Caso puro iterador (microbench) | 1,02× (sem regressão — ruído) |
| Decisão do harness | `"len-fastpath accepted: CI lower bound 0.0041 > 0 with corrected p <= 0.05"` |
| Custo da decisão | 6,1 s |

## Por que este case importa mais que EC1/EC2

1. **Código que não é nosso:** o harness nunca tinha visto o alvo; o manifesto
   descreveu tudo (build implícito, teste, benchmark, variante patch).
2. **Mudança mínima, prova máxima:** 6 linhas inseridas, 0 removidas; semântica
   preservada (sized não são "consumíveis" mesmo; iteradores caem no caminho antigo).
3. **Honestidade no mix:** o número-chefe (+55,5%) dilui propositalmente o
   microbench chamativo (3.600×) com 30% de iteradores — o ganho reportado é o
   de uma carga plausível, não o do melhor caso.
4. **Gate antes de glória:** se `pytest -k ilen` falhasse sob a variante, não
   haveria medição (fail-fast), não "vitória".

## Limites declarados

- O ganho depende do mix de cada chamada real; medimos um mix plausível, não "o" mix.
- `len()` em objetos com `__len__` custoso/exótico herda o custo deles (raro; documentado no PR).
- O PR pode ser recusado por gosto de API ("mantenha simples") — a entrega EC3 é a
  medição + o pack, não o merge.
