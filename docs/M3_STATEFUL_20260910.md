# M3 — Stateful fuzz do pipeline sweep→decide→export (2026-09-10)

`tests/test_pipeline_stateful.py`: `RuleBasedStateMachine` (hypothesis,
dev-dep) que constrói um `BenchmarkSweep` run a run — valores hostis
(NaN/±inf/1e300/subnormais), nomes hostis (vazio, `../`, unicode), runs
quebrados, policies no limite — intercalando `decide_best_candidate` e os
4 exports. Invariantes: decide nunca levanta; veredito ∈ {None} ∪
candidatos; decide determinístico; exports existem e o JSON faz roundtrip
(NaN-aware); `to_dict()` sempre serializável (checados após cada passo).

Settings explícitos no `TestCase` (não toca os profiles globais de
`test_stats_properties.py`): fast 15×25 (~3 s), ci 60×40 (~14 s) via
`HYPOTHESIS_PROFILE=ci`. Slow-marked; CI roda tudo.

## Achados (5 fixes, todos replay-neutros)

1. **`OverflowError` em `bench._stddev`** (exemplo minimal: valores
   `[1e300, 0.0]` — `(5e299) ** 2` levanta). Fix: `except OverflowError →
   inf` (degrada, nunca crasha).
2. **Mesmo `OverflowError` em `stats.effect_size`** (variância) e
3. **em `stats._jackknife_acceleration`** (`**3`/`**1.5`) — alcançáveis via
   decide com deltas enormes. Fix: `inf` na variância (dz→0), `0.0` na
   aceleração (pula a correção). Goldens do M1 intactos (caminho só
   dispara onde antes crashava).
4. **`confidence=1.0/0.0` → `StatisticsError` críptico** do
   `NormalDist.inv_cdf` — alcançável via CLI (`benchmark_project_target.py`
   repassa `--confidence`). Fix: `ValueError` amigável em
   `bca_bootstrap_ci`/`percentile_ci` (fail-fast na entrada).
5. **`min_pairs=0` tentava comparação com zero pares** (`ValueError` de
   `paired_deltas` vazias). Fix: `required = max(1, policy.min_pairs)` no
   decide + mensagem coerente.

## Lições de modelagem (pagas com probe)

- **Sem grid denso inicial, o fuzz é vazio**: 25 decides, 0 comparações
  (regras uniformes diluem os runs). `@initialize` planta 3×6 pareado.
- **Sem offsets sistemáticos, sem wins**: n≤4 não vence sob Holm-2 nem
  matematicamente (piso MC 1/16 > 0.05/2). Grid 3×6 com offsets
  (baseline 10 / a 12 / b 8): 48 wins em 79 decides + 31 Nones.
- **Determinismo com NaN exige comparação NaN-aware**: dicts idênticos com
  `nan` falham em `==` — era o modelo, não o produto (Q1.5 agiu certo).
