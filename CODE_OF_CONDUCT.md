# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. In short: be kind, be honest about numbers, no harassment, no faked benchmarks.

Enforcement: open an issue titled `[CoC]` or contact the maintainer. Violations may
lead to temporary or permanent bans from the project spaces.
