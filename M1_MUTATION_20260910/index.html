    M1 — Mutation testing the statistical core (2026-09-10)

    Timeboxed mutation run on mycelium_accel/stats.py (the decision math: BCa bootstrap, sign-flip permutation, Holm/BH, effect sizes, sequential racing). Tool: mutmut 3.7.0, serial (--max-children 2, no xdist — workers hide trampoline hits), run from an isolated venv without the package installed (an editable install shadows the mutants/ copy).

    Config lives in pyproject.toml [tool.mutmut]. Runs are manual, never in CI.

    Run 1 (baseline battery)

    681 mutants: 490 killed / 28 no-tests / 163 survived (72% overall, 75% excluding no-tests). Below the 80% gate, so every survivor was triaged by hand. Verdicts:

    • 92 killable: real gaps in the battery — 89 killed by the new tests/test_stats_mutation.py (38 tests, 0.4 s, stdlib-only, inner loop) in run 2, plus 3 fixed after run 2 exposed gaps in the new tests themselves (see below).
    • 71 accepted-equivalent: behaviour-neutral by proof, by contract, or unreachable in practice. Each class is justified below; re-triaging them on a re-run is a waste of time unless the code changes.

    What the 85 killable survivors taught us (all fixed)

    1. Payload fields were write-only. metric/mean/median/confidence/ prob_superior/direction flow into JSON but no verdict path reads them — 13 compare_paired_metric mutants (incl. =None on every field) survived. Fixed with exact golden pins on all fields.
    2. Subprocess determinism tests are mutation-blind. The bit-identical test spawns children that import the unmutated package (cwd on sys.path), so all five seed=None mutants survived. Fixed with in-process determinism tests (same call twice → identical).
    3. Acceleration was unpinned. The jackknife **3, /6.0, /denominator and both _adjust formulas survived — the battery only checked CI shape, never the correction terms. Fixed with a hand-computed acceleration test + BCa goldens (incl. a symmetric dataset with accel exactly 0.0, which pins the denom == 0 guard).
    4. Default min_rounds path untested. All racing tests passed min_rounds explicitly; 10 default-formula mutants (incl. crashers) survived. Fixed with default-path tests; elimination timing is now observed through the stored comparisons' n_pairs.
    5. lower_is_better racing untested. direction=-1 corruption survived end to end. Fixed with a lower-better race + direction=-1 compare test.
    6. Percentile CI pinned only on constant data. Ordering, n=2, and the alpha formula were free. Fixed with a golden + ordering + nesting.
    7. MC interiors unpinned. Floor p-values (0.001) hide broken mechanics (+= → =, negated sums, tolerance ×1e12 all give ~0 on strong effects). Fixed with exact goldens on null data (p = 0.472 / 0.914).
    8. Correction defaults + wiring. Both method="holm" defaults and the p_value_corrected assignment were unpinned. Fixed with hand-computed Holm/BH pins.

    Accepted-equivalent ledger (78)

    Error-message wording (29). ValueError(...) → ValueError(None/ XX../lower/UPPER) in bca(4), effect(4), mtc(1), paired(8), percentile(4), racing(3), sign_flip(5). The exception type is pinned; the prose is not part of any contract. Deliberate: pinning prose makes messages uneditable.

    Arbitrary default constants (8). seed 13→14, n_bootstrap 5000→5001/2000→2001, n_permutations 10000→10001 in bca(2), percentile(2), compare(2: #3 seed, #4 n_bootstrap), sign_flip(2). Any value is equally valid; what matters — determinism + distribution — is pinned elsewhere. Pinning seed=13 exactly would overfit to an arbitrary number. (Exceptions: compare#5 and racing#4 were killed — the racing golden pins an MC value computed under the default n_permutations/seed, since racing doesn't forward them. Pinning the default's mechanical output is fine; the constant's wisdom is still unpinned, as intended.)

    Exact-enumeration symmetries (6). _exact_sign_flip #13 (double counting: both loop halves over-count identically, ratio unchanged), #19 (global sign negation is a bijection on sign patterns), #23/#24 (mask-bit polarity is a bijection), #3/#6 (>= vs > at observed - 1e-12: the offset value is not a sum, equality is measure-zero).

    Jackknife bit-neutral survivors (2). #11 (/(n−1) → *(n−1): power-of-2 rescaling is exact in binary float, so num/den keep their mantissas and the ratio is bit-identical), #34 (else 1.0: denom = 0 ⟺ constant data, and any quantile of identical bootstraps is the constant — pinned by the constant-data property test). Note: #5 (total +1.0 shift) and #12 (/(n+1) rescale) were first classified here — algebraically neutral over the reals — but run 2 killed them: exact goldens pin bits, and non-power-of-2 shifts/rescales leave float dust. That is deliberate: silent float changes in decision math should force a review, and goldens force it.

    Redundant guards absorbed downstream (7). bca#56 (alpha=(1+c)/2 swaps the two tails; the defensive q_lo>q_hi swap restores the identical interval); bca#90/#102 (clamp 1.0→2.0: _adjust is a CDF output, already ∈ [0,1]); bca#103 (>→>=: swapping equal values is a no-op); mtc#67 (BH cap 1.0→2.0: the running minimum starts at p_max ≤ 1, so raw values > 1 are absorbed); mtc#26 ([0.0]*m→[1.0]*m: every slot is overwritten); mtc#48 (running=2.0: first min(2.0, v≤1) is v).

    Unreachable defensive guards (6). bca#72/#73 (denom = 1e-12 value: denom == 0.0 needs a·(z0+za) = 1 exactly — measure-zero; the guard's existence is what matters); bca#104 (the q_lo>q_hi swap arm: needs 1/a − z0 ∈ (−1.96, 1.96), i.e. |z0| > 4 with sign cancelling the skew that produced it — 4000-dataset search + analytic skew argument say unreachable; the guard stays as defence); sign_flip#33/#36 (>=→> at observed − 1e-12 on the MC path: float sums never equal the offset value); sign_flip#58 (< 0.5→<= 0.5: differs iff random() == 0.5 exactly).

    Out-of-contract inputs (9). compare#63/#64 + paired#14/#15 (direction = 0 mapping: contract is ±1; 0 is unmapped); compare#1/paired#1/racing#14/#16 (non-negative default direction values behave identically through >= 0); racing#46 (len(alive) <= 1 → < 1: alive is never empty — the incumbent is never removed — and with one alive the guarded loop body is a no-op either way).

    Order-preserving / argmax-neutral (3). racing#50 (_mean ×n² feeds only an argmax over equal-length score lists); racing#88 (champion key ×n², same); effect#40 (float("INF") == float("inf"), case-insensitive).

    Valid-algorithm variants (1). sign_flip#42 (7≤n≤16 → ≤17: the exact path is more accurate; the boundary is a performance choice, both paths valid). Racing#77-adjacent payload Nones are killed (golden + to_dict); noted here only because the verdict path never dereferences RaceResult.comparisons (informational only). racing#62 (continue→break at incumbent) was classified here as unkillable-by-construction (the behaviour change depends on set(alive) iteration order, i.e. hash seed) — but run 2 killed it: under that run's hash seed the incumbent came first and the break skipped all challengers. Counted as killed, flagged as hash-fragile: a different hash seed may resurrect it. Robustly killing it would require hash-seed control, which is not worth it for a single mutant.

    Quantile clamp edge (0 — killed, ledger corrected). _quantile#22 (len−1→len−2) was first classified equivalent ("binds only at q = 1 where frac = 0"). That proof was wrong: the mutant binds whenever lower = B−2 with frac > 0, flattening the whole top quantile bin (interpolating V[B−2]→V[B−2] instead of V[B−2]→V[B−1]). A real mutant, killed by the goldens. Kept here as a warning: hand proofs about float indexing deserve a second pair of eyes.

    Run 2 (with the killer battery)

    681 mutants: 579 killed / 28 no-tests / 74 survived → 88.7% excluding no-tests. Gate cleared (≥ 80%). Zero regressions: all 74 survivors are a subset of run 1's 163.

    Reconciliation: 89 newly killed = 83 predicted + 6 ledger surprises (jack#5/#12 float dust, qnt#22 wrong proof, cmp#5/race#4 default-MC pins, race#62 hash-fragile — all documented above). Of the 74 survivors, 71 are the accepted ledger; the other 3 were gaps in the new tests, fixed the same day:

    • apply#7: the BH test data ([0.01, 0.04]) gives identical values under Holm — BH and Holm were never separated. Fixed with [0.03, 0.04] (bh → [0.04, 0.04], holm → [0.06, 0.06]).
    • race#83/#85 (champion by name): every scenario eliminated all but one candidate, so the champion key never mattered. Fixed with a no-elimination race (futility_margin=-100, all three survive).

    The 3 fixes were verified by targeted simulation (mutants applied to a scratch copy of the package; the fixed tests fail against them), not by a third full run — the gate was already cleared with margin. Effective standing: 582 killed / 71 survived-classes-accepted (89.1%).

    Reproducing

    pip install mutmut==3.7.0          # isolated venv, package NOT installed
rm -rf mutants .mutmut-cache
mutmut run --max-children 2        # ~20 min serial; no -n, ever
mutmut results

    Methodology notes (paid for in debugging time): run from a venv without the package installed; keep source_paths as the package dir with only_mutate on the target file; pass -p no:randomly (xdist/randomly break trampoline association → bogus "no tests"); select test files via pytest_add_cli_args_test_selection (TOML lists — setup.cfg splits list values only on newlines).
